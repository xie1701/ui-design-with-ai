# 质量评分与停止规则

## 评分原则
每项 0–10；没有证据就不打高分。总体分数不是简单平均：任务清晰、可用性、可访问性任一明显失败，不能用视觉分数抵消。

- **0–3**：任务难以完成或系统不成立。
- **4–5**：能运行，但层级、身份或状态明显粗糙。
- **6–7**：有可取方向，仍有模板感或关键细节缺失。
- **8**：成熟且一致，少数重点仍可提升。
- **9**：专业工作室级别，在目标情境下有鲜明判断，细节和克制都成立。
- **10**：极少使用；只有在目标、内容、状态、无障碍和实现风险都经过验证且没有明显遗憾时才考虑。

## 自动迭代停止
- 首轮只修复最大 3 个问题，不要同时改颜色、布局、字体和动效。
- 最多连续 3 轮；每轮保存截图和分数。
- 连续两轮总分不升，或某一轮新增问题多于解决问题，回到 Define。
- 达到稳定的 8–9 分且剩余问题属于主观偏好时停止，不为追分无限加装饰。
- 关键任务、无障碍、响应式或安全问题未解决时，即使视觉分高也不能交付。

## 视觉 QA 表
| 检查 | 通过证据 |
|---|---|
| 首屏 | 主要任务、状态、CTA 在目标视口可见 |
| 设计身份 | 视觉语言在所有页面、状态和断点一致；冒险点有辨识度且不伤任务 |
| 结构 | DOM/视觉顺序符合用户任务，而非只好看 |
| 状态 | loading/empty/error/success/disabled 都可理解 |
| 响应式 | 320px、768px、1440px 及长文案不溢出 |
| 键盘 | 每个操作可到达，focus-visible 清晰 |
| 对比度 | 文本、控件边界、焦点按 WCAG 2.2 检查 |
| 动效 | reduced motion 有降级；无自动播放干扰 |
| 内容 | 没有 lorem ipsum、重复 CTA、假承诺或无意义标签 |
| 资产 | 图片/视频有 fallback、尺寸和授权/密钥边界 |
| 工程 | lint、typecheck、build 和关键路径检查通过 |
