# design-identity · 晨光声纹台

方向：**A 声纹台 × C 晨昏光谱**（吸收 I 的手写批注样式、G 的标本标签）
种子：`xLwAGOMwKpzmDkST`

## 一句话身份

**这是一个在天亮过程中被读出来的页面。** 读者往下滚，天色从夜转晨；声音不是被描述的，是被画出来、按出来的。

## 视觉隐喻

| 隐喻 | 落到页面上的什么 |
|---|---|
| **夜（未发声）** | 深蓝底，正文的默认底色；未激活的状态、被折起的过去 |
| **朝（发声）** | 一束琥珀色的光。它有一个**角度**——角度由滚动位置决定，从左侧低角度升到顶部 |
| **鸣（声音的形状）** | 声纹：一条真实绘制的波形。它不是装饰——它由音频数据或文本散列确定性生成，可重复 |
| **标本标签** | 时间轴节点、章节编号：等宽字、小号、宽字距，像贴在实物上的标签 |
| **手写批注** | 引用块：偏暖的纸色底 + 左侧一条手写的"笔迹线"，与正文区分 |

## Token

### 颜色

| token | 值 | 用途 | 约束 |
|---|---|---|---|
| `--night` | `#08131F` | 页面底 | 正文底色，所有对比度以它为基准 |
| `--night-2` | `#0E1F31` | 抬升面（卡片、面板） | 与 `--night` 的差要看得见，但不做发光 |
| `--night-3` | `#15293D` | 边界线、分隔 | 非文本，3:1 不作为要求 |
| `--dawn` | `#F2B33D` | 朝阳的黄：主强调、当前状态、主按钮底 | 深底上的文字用 `--night`，对比度 ≥ 4.5:1 |
| `--dawn-soft` | `#F7D08A` | 光的边缘、次级强调 | 只作大面积光晕与大字，不作小字 |
| `--voice` | `#F4F1EA` | 正文文字（暖白） | 在 `--night` 上 ≥ 12:1 |
| `--voice-dim` | `#A9B4C2` | 次要文字（标签、说明） | 在 `--night` 上必须 ≥ 4.5:1 |
| `--resonance` | `#7FA6C4` | 冷色辅助：AI / 机器侧的标识 | 与 `--dawn` 明确分工：**人声=暖，机器=冷** |
| `--ink-on-dawn` | `#20180A` | 琥珀底上的文字 | 在 `--dawn` 上 ≥ 8:1 |

### 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 展示（标题） | `"Songti SC", "Noto Serif SC", STSong, serif` | 章节标题、页标题、大字 |
| 正文 | `"PingFang SC", "Noto Sans SC", "Hiragino Sans GB", system-ui, sans-serif` | 所有段落与列表，长文阅读 |
| 标签/元数据 | `ui-monospace, "SF Mono", Menlo, monospace` | 章节编号、时间码、标本标签 |

字号：正文 17px（390 视口）/ 18px（≥768），行高 1.85。**全页最小可见字号 16px**（提案原文属"主体文案"，不缩排）。

### 布局

- 主轴：一条常驻的**声纹轨**。≥1024 时在左侧 72px 宽；<1024 时退化为页面顶部的一条 3px 声纹进度条（不占内容宽度）。
- 内容列：单栏，最大行宽 `34em`，左对齐；**不使用居中 hero**。
- 章节：七章按原顺序，编号用 `一 … 七` 的汉字（来自原文标题），标签用等宽字。
- 非对称：引用块、互动组件相对内容列**向右出血 24–40px**；正文不出血。这样页面有"手写批注压在正文边上"的感觉。

### 动效

| 动效 | 触发 | 说明 |
|---|---|---|
| 光角推进 | 滚动 | `--dawn-angle` 由滚动进度驱动（0 → 1 映射 -18deg → 4deg）；只改变 `background-image` 的角度与 `opacity` |
| 声纹生长 | 滚动 + 发声 | 左轨声纹的已完成部分随滚动进度填充 |
| 发声脉冲 | 用户手势 | 按下时画一条新波形，200ms 内落定；不循环 |
| 章节入位 | 滚动进入视口 | 位移 12px + 透明度，一次，不循环 |

reduced-motion：光角固定在 50% 位置；声纹静态绘制完成态；所有 `animation` 名为 `none`；互动功能全部保留。

## 允许冒险区

1. 首屏**不放主 CTA**。这是一份提案，不是获客页；首屏的"动作"是**按一下听见一声**。
2. 首屏标题用大号宋体、宽字距，允许在 390 上占 3 行。
3. 左轨声纹在 ≥1024 时是常驻元素，允许它占掉 72px 的横向空间。
4. 五、六章的表格允许做成"前后对照账簿"式的两栏，左栏压暗。

## 禁止项

- 禁止紫色 / 蓝紫 AI 光效、霓虹 glow、无意义渐变。
- 禁止等宽卡片阵列（三卡/四卡一排）。
- 禁止 pill 滥用；圆角只用于确实需要边界的容器。
- 禁止无限循环动画。
- 禁止假数据：不出现学员人数、好评数、增长率、"已有 N 位家长选择"。
- 禁止空洞词：赋能、解锁、重新定义、一站式、闭环。
- 禁止把概念演示写成已上线功能。每个互动组件必须带可见的「概念演示」标注。
- 禁止改动提案文案：不新增、不删减、不"优化"任何一句。
- 禁止用视觉分替代工程验证。

## 反例（明确不要的样子）

> 深蓝底 + 紫色光晕 + 三张等宽圆角卡片 + 一个居中大标题 + 一个橙色"立即咨询"按钮 + 一排假 logo 墙。

这是最容易滑向的"AI SaaS 落地页"默认形态，本页从布局（非对称、无居中 hero）到内容（无 CTA、无假数据）都刻意避开。
