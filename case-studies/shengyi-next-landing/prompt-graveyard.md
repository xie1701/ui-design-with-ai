# Prompt Graveyard · 生意说首页互动化

只记录**试过但失败或必须放弃**的方向与写法，供后续任务避开。每条给出：试了什么、为什么失败、改用什么。

## 方向级（写在 directions.md 之前的探索）

1. **声音显影室（长按让文字从暗处显影）**
   - 失败原因：视觉上必须依赖径向渐变 + 模糊才能成立，而本页有硬合同禁止 `*-gradient(`、`backdrop-filter` 与 `blur`。
   - 改用：实色块 + 1px 规则线 + 声波条形建立「声音」的质感。

2. **字幕滚动 / 时间轴 / 手写翻页**
   - 失败原因：都倾向持续或循环动效，与「动效不循环、只改 transform/opacity」的合同冲突；时间轴还暗示「15 分钟就出结果」，接近效果承诺红线。
   - 改用：由用户动作触发的离散状态变化（切换 → 重绘；确认 → 生长；撤销 → 收起）。

3. **对照尺（左右拉杆对比「自己硬想」vs「说出来」）**
   - 失败原因：必须构造「你自己想不出来」的画面，与 `PRODUCT.md`「不把经营者塑造成不会思考的人」直接冲突。
   - 改用：把对比放在「原话 vs AI 整理」之间，而不是「人 vs 机器谁更行」。

4. **出摊台 / 小票机**
   - 失败原因：隐喻错位——把内容当「货」、把理解当「消费凭证」，会误导对产品的理解。
   - 改用：工作台（台面）——摆上去、被加工、由主人拍板。

## 写法级

5. **把演示数据直接写在客户端组件里**
   - 失败原因：`tests/landing-bc-contract.test.mjs` 的文案断言读的是 `page.js`，数据搬进客户端组件后断言全部失守；同时对外文案散成两处，无法一处审计。
   - 改用：客户端岛**不含任何用户可见文案**，数据与文案由 `page.js` 以 `sentences` / `copy` props 传入。

6. **用 `Math.random()` 生成声波形状**
   - 失败原因：SSR 与客户端首帧不一致，会产生 hydration 分歧；同一句每次刷新形状都变，破坏「这句话有自己的形状」的说法。
   - 改用：由句子文本的确定性散列（FNV-1a 变体 + 逐位混合）派生高度百分比。

7. **用绝对高度（px）写声波柱**
   - 失败原因：柱高固定为 6–30px，容器高 18–22px 时柱子会溢出到引文行里，视觉上撞字；且不同断点要维护两套数值。
   - 改用：柱高写成容器高度的百分比（`height: 20%–100%`），容器高度按断点给，柱子自动适配。

8. **确认按钮做成深色实心主按钮**
   - 失败原因：首屏同时出现两个同尺寸的实心按钮（确认 + 橙色转化 CTA），层级打架；独立评审指出「把人拍板的关键动作画成了机器色」。
   - 改用：白底 + 1.5px 墨边 + 橙色声音点；橙色实心只留给页面唯一转化 CTA。

9. **给对比页的遮罩层和右上角标签都起名 `after`**
   - 失败原因：`.slider .after { position: absolute; inset: 0 }` 同时命中了 `<span class="tag after">`，把标签拉成整屏并铺上不透明底色，**把两张截图全盖住**，表现为「图片加载失败」。
   - 改用：遮罩叫 `.pane`，标签叫 `.tag-after`，避免与结构类同名。教训：CSS 类名与「状态词」同名时要显式区分命名空间。

10. **把 `overflow-x: auto` 的纸签行当成「可滑」就够了**
    - 失败原因：独立评审在 390 与 320 截图上判为「像渲染坏了」——最后一个纸签被右边缘切掉半个字，且没有渐隐/箭头提示。
    - 改用：文案收为 2 字 + 收窄内距，让 6 个纸签在 390 一行放得下；320 宽直接换行。目标是不出现半字截断，而不是「让它能滚」。

11. **在 `next dev` 运行时执行 `npm run build`**
    - 失败原因：两个进程争同一个 `.next` 目录，dev server 开始返回半成品状态（页面看起来像被缩放、样式错乱），截图与 DOM 度量互相矛盾，白白浪费一轮排查。
    - 改用：先停 dev，清空 `.next`，用生产构建 + 生产服务器出图。截图证据本来就该来自生产构建。

12. **把「共享 chunk 大小」当作「路由 First Load JS」**
    - 失败原因：把 103 kB 的 shared chunk 当成落地页路由体积，导致改动代价被高估为 +5 kB。QA 用 HEAD 版本另建副本实测，真实基线是 917 B / 107 kB，改动后 2.18 kB / 108 kB。
    - 改用：报体积时同时写清「路由自身大小」与「First Load JS」，并给出基线的测量方法。
