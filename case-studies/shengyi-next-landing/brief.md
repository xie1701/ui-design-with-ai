# Brief · 生意说 Web 首页（`/`）趣味性与互动性优化

- 任务模式：`REDESIGN`（主）+ `COMPONENT`（新增交互岛）+ `QA`（合同回归）
- 对象仓库：生意说 Web 应用（Next.js 15 App Router，非公开仓库；本机路径已省略）
- 对象文件：`src/app/page.js`、`src/app/landing.module.css`（+ 新增客户端交互岛）
- 基线：`https://sy.unfog.cn/`（生产）与本地生产构建 `PORT=3999 NODE_ENV=production node server/index.js`（同一份源码）
- 本轮日期：2026-09-21

## Design Read

这是一个面向**懂自己生意、但不会做 IP、不会系统做内容的中国中小商家老板（首要用户）**的**移动优先 Web 落地页**，解决**首次打开时无法亲手验证「我说的话会被怎么整理、我是否还掌控结果」**的核心任务，采用**暖纸画布 + 权威橙（人声/生长）+ 信任蓝灰（结构/确认）**的既有品牌语言，优先保证 **390×844 首屏可读懂、文案零虚假承诺、合成演示显式标注、无渐变/无模糊/无无限动效的克制工艺**。

## 当前行为与证据

- **主要用户与使用情境**：未注册/未登录的首次访客，多数在手机微信内打开（`WechatShare` 仅在 MicroMessenger 内激活）。`PRODUCT.md:7` 定义为「懂自己的生意，但不会做个人 IP、不会系统做内容」；`PRODUCT.md:11` 要求「数秒内理解产品价值」。
- **当前如何完成任务**：页面用静态文字 + 静态示意卡讲清「原话 → AI 整理 → 用户确认 → 生成内容」。全页只有 4 个 `<Link>`，**零 JS 交互**（`src/app/page.js` 无任何 hooks）。
- **可观察障碍**：
  1. 产品最关键的差异点（「未确认不进入生成」= 用户掌控）只能靠阅读理解来相信，访客无法亲手做一遍；机制被**声明**，没有被**演示**。
  2. 首屏静态示意卡与第二段「你确认之前」三格轨道用**同一句原话讲同一件事**，属重复叙事。
  3. 桌面端 hero 下方存在大片无内容空白（`before/screenshots/desktop_full.png`，1440×2491）。
  4. `landing.module.css` 有 5 个死类（`trustSection` / `trustGrid` / `trustLead` / `boundaryList` / `policyLinks`，定义于 :17、:73、:275、:283、:392–438，page.js 无引用）。
- **证据来源**：生产站点实拍截图（390×844、1440×900）；本地 dev 渲染（`http://127.0.0.1:3999/` → 200，43,781 B）；源码通读；仓库内既有评审文档（`.impeccable/critique/2026-08-29T12-38-11Z__src-app-page-js.md`、`REVIEW_2026-09-17.md:49`）。
- **证据强度**：
  - 「零 JS 交互」「死 CSS」「首屏高度占用」= **已测量**（源码 + 截图像素）。
  - 「访客因为不能亲手试而降低信任」= **间接证据 + 团队判断**（`.impeccable` critique §6.2 指出 landing 说服力不足、只有构造示意；**没有真实用户测试**）。
  - 「增加互动会提升转化」= **未验证假设**，本轮不承诺任何转化结果。
- **已有替代方案及其不足**：`.impeccable/mocks/decision/` 下三张概念图（A 痛点 / B 一句话前后 / C 掌上经营底稿），2026-08 已选定 B+C 并落地。替代方案的不足是：三张都是**静态构图**，都没有把「确认」做成可操作对象。

## 问题定义

- **已确认事实**：
  - 首页为 Server Component，`tests/landing-bc-contract.test.mjs:57` 断言其**不得**引入 `useState` 等 hooks、不得依赖 `window`/`document`。
  - `DESIGN.md:976–995`（§7.1）为落地页视觉与交互契约：方向种子 `605b55da`；390×844 首屏必须出现直接价值、B 演示、唯一主 CTA、访谈时长与积分；不使用渐变、蓝紫 AI 光效、假证言、假规模；合成原话标「场景示意」、合成产物标「演示内容」；文字不小于 16px；动效只表达一次「橙色声音进入蓝灰结构」，只改 `transform`/`opacity`，不循环。
  - `tests/landing-bc-contract.test.mjs` 另有硬断言：CSS 禁 `*-gradient(`、禁 `infinite`、禁 `backdrop-filter`/`blur`；必须有 `prefers-reduced-motion` 且 `animation: none`；二维码类在 <768px `display:none`、≥768px 恢复；交互样式至少 44px 命中区；`landing.module.css` 内所有字面 `font-size: Npx` ≥ 16。
  - 演示内容只能重组同一演示原话中已有的事实（`DESIGN.md:988–990`；测试禁 `社区店十二年`）。
  - `PRODUCT.md:47`：目前没有可公开使用的真实客户案例、脱敏成果、评价、规模或增长数据。
- **问题假设**：把静态示意换成**可亲手操作、且操作结果与产品真实机制一致**的演示，比增加说明文字更能让访客理解「我掌控结果」。这是假设，不是已验证结论。
- **核心问题陈述**：
  > 一个不会做内容的经营者，在手机第一次打开 `/` 时，只能在静态文字里读到「原话 → AI 整理 → 你确认 → 生成内容」；因为页面上没有任何可操作对象，他必须靠阅读理解来相信这套机制，于是最关键的差异点（**我确认了才走下一步**）退化成一句需要被相信的声明；解决后应看到：他能在首屏内亲手挑一句最像自己平时说的话，看到它被整理成一张理解卡，**只有自己按下确认**才会长出内容选题，并且可以撤销。
- **成功信号**：
  1. 首屏内出现可操作对象（不是装饰按钮），且其初始高度不把主 CTA 挤出 390×844 首屏。
  2. 访客可完成一次完整循环：选原话 → 看到整理 → 自己确认 → 看到产物 → 撤销。
  3. 未确认状态下产物**不存在于 DOM**（不是隐藏），机制被结构而不是文案表达。
  4. 全流程可键盘完成、焦点可见；`prefers-reduced-motion` 下直接呈现终态。
  5. 既有静态合同（Server Component、无渐变/模糊/无限动效、≥16px、44px 热区、合规标注、二维码断点）全部保持通过。
- **失败代价**：访客仍只读到声明 → 继续把生意说当作「又一个 AI 写作工具」；或为了「有趣」引入违反品牌与合规契约的视觉语法（渐变光效、假数据、无限动效），污染已上线的信任资产。
- **非目标**：
  - 不调用真实模型、不要求登录、不请求麦克风权限（首次访客不该被要求授权）。
  - 不制作假客户证言、假规模、假增长数据、效果承诺。
  - 本轮不改小程序 guest 页、不改后端、不改品牌 token。
  - 不追求转化率数字提升的承诺（无 A/B 与流量数据）。

## 内容与适用状态

- **核心内容与真实文案来源**：
  - 页面既有文案（首屏承诺、时长、积分、gate 声明）来自 `src/app/page.js` 与 `DESIGN.md` §7.1，**原文保留**。
  - 新增演示原话为**合成的经营口语句**，每句就近标注「场景示意」；其整理结果与选题标注「演示内容」。
  - 演示事实纪律：每句原话的「AI 整理」与「可生成」**只允许重组该句已出现的事实**，不补写行业、年限、客户特征、面积、价格或效果。

## 平台与约束

- **Web 类型**：站点（Next.js 15 App Router 服务端渲染的营销落地页）。
- **目标视口与浏览器**：390×844（首要，微信内置浏览器）、768–1023px（Pad）、1440×900（桌面）；system Chrome 截图验证。
- **输入方式**：触摸（首要）、鼠标、键盘（Tab/Enter/Space）；读屏（结构语义）。
- **品牌资产与现有设计系统**：`tailwind.config.js` + `src/app/globals.css` 语义 token；`brand-signal #F2782C`（不作白底小字）、`brand-signal-soft #F9BC96`（不作文字或边界）、`brand-trust #5C6F87`（结构/主按钮）、`brand-action #B84B14`（白字高对比）；字体走本地系统栈（衬线 `Songti SC`/`STSong`，无衬线 `PingFang SC` 等），零远程字体请求；复用 `ConfirmBadge`、`SiteFooter`。
- **技术栈、依赖、API**：Next.js 15.5.24 / React 19.1.0 / CSS Modules / Tailwind；不新增依赖；不新增 API 调用。
- **不可改变的内容**：`tests/landing-bc-contract.test.mjs` 与 `tests/p0-web-truth.test.mjs` 锁定的语义（Server Component、方向契约注释含 seed `605b55da` 与精确 FINISH 句、CTA 目标、合规标注、字号、热区、二维码断点、reduced-motion 终态）。
- **敏感、隐私或不可逆操作**：无支付、无删除、无权限申请。截图外发前检查：页面含备案号与公开小程序码，均为已公开信息；演示原话为合成数据，不含任何真实客户信息。
