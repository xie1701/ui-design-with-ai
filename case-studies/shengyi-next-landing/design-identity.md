# Design Identity · 生意说首页「试说一句台」

## 一句话身份

生意说首页像**一张摆在街边的工作台**：老板把一句平时说的话摆上台面，台面把这句话收进蓝灰的格子里整理成一张理解卡，而**只有老板自己按下确认，台面才会把后面的东西放出来**；它绝不应像**一个会自己下结论的 AI 展示柜**，也绝不应像**通用 SaaS 的功能卡片墙**。

## 设计旋钮

- `DESIGN_VARIANCE`：**MEDIUM-HIGH**。可观察锚点：全页只有**一处**非常规空间决策——台面满宽出血、原话纸条向左溢出内容列并轻微倾斜（`-0.35deg`）；其余区块仍守熟悉的单列/双列阅读路径，导航与 CTA 位置不变。
- `MOTION_INTENSITY`：**MEDIUM**。可观察锚点：动效只解释因果——切换行业 → 声波按新句重绘；确认 → 声波收束 + 产物生长；撤销 → 产物收起。只改 `transform` / `opacity` / 高度上限，不循环、不承载唯一信息；`prefers-reduced-motion` 下直接呈现终态。
- `VISUAL_DENSITY`：**LOW-MEDIUM**。可观察锚点：单一主任务（试一句）；台面同时并发信息 ≤ 3 块（原话 / 整理 / 产物）；台面外部保留大留白，台面内部紧凑分组。

## 系统规则

- **布局与负空间**：内容列 `min(100%, 1180px)`；台面**满宽出血**（`margin-inline: calc(50% - 50vw)`）打破内容列边界；桌面原话纸条向左超出内容列 16px；台面右侧留不对称负空间（整理卡不贴右边界）。
- **字体角色与层级**：**人说的话用衬线**（`"Songti SC", STSong, "Noto Serif SC", serif`，≥18px，行高 1.6）；**机器的结构用无衬线**（既有 PingFang 栈）；计数用 `font-variant-numeric: tabular-nums`。这条分工是本页最主要的排版决策。
- **色彩角色**：`--landing-voice #F2782C` 橙 = 人声证据（声波、原话标记点、主 CTA）；`--landing-trust #5C6F87` 蓝灰 = 机器结构、确认、边界；`--landing-canvas #FAF7F2` 暖纸 = 画布；`--landing-bench #F3EDE4` = 台面底；`--landing-tape #FDF0E4` = 原话纸条底。橙色**永不作小字**。
- **材质、图像或 3D**：无位图、无 3D、**无渐变**。材质只由 **1px 规则线 + 实色块 + 声波条形** 建立。
- **控件与容器**：新增容器一律直角或极小圆角（≤3px）；**不新增 pill**；行业签做成**纸签**（矩形、1px 边、选中时橙底边线 + 深墨字），不做圆角胶囊。
- **动效因果与 reduced-motion**：见旋钮；`prefers-reduced-motion: reduce` 下 `animation: none`，声波静态、产物直接出现、橙色收束线置静态终态（保留既有 `.organizeBlock::before { opacity: 0 }` 断言）。
- **响应式时保留什么、重排什么**：保留 = 台面满宽出血、橙/蓝灰分工、衬线/无衬线分工、确认门禁语义、纸签倾斜；重排 = 桌面横向台面（原话左 / 整理右）→ 移动单列堆叠；纸签桌面一行 → 移动横向可滑。

## 冒险与熟悉

- **可以冒险**：台面满宽出血、原话纸条溢出并倾斜、声波成为页面主角、桌面横向台面、确认前产物**不存在于 DOM**。
- **必须熟悉**：主 CTA、登录入口、页脚备案、切换控件（按钮组语义）、确认/撤销（按钮）。
- **禁止视觉语法**：渐变、`backdrop-filter`/模糊、无限循环动效、pill 滥用、等尺寸图标卡阵列、装饰性 `01/02/03` 编号、eyebrow/kicker、假证言/假规模/假增长、橙色小字、emoji 堆砌、音效。
- **可接受的例外及任务理由**：唯一例外是原话纸条的 `-0.35deg` 旋转。理由是「人说的话」需要与「机器的结构」在物理感上区分开；旋转不承载任何信息，也不是动效，reduced-motion 下保留。

## 状态与断点

- **适用状态如何保持身份**：所有状态都发生在台面上（待确认 / 已确认 / 已撤销 / 切换行业）。状态变化靠**结构出现与消失**表达，不靠颜色闪烁；状态变化通过 `aria-live="polite"` 播报。
- **移动端如何压缩而不退化成模板**：台面保持满宽与实色边界；原话纸条保留倾斜与衬线；声波缩短但仍是主角；纸签横向可滑且保持 ≥44px 命中区。
- **长文案/本地化边界**：演示原话最长约 30 字，移动端 3 行内；选题标题最长约 24 字，允许换行不截断。

## 反例

- **看起来像什么说明方向失败**：
  1. 台面退化成「标题 + 三个等宽卡片」的说明块。
  2. 声波变成装饰性分割线，与正在展示的那句话无关。
  3. 「确认」变成纯视觉开关，产物在未确认时仍存在于 DOM。
  4. 出现渐变、光晕、模糊或无限漂浮动画。
  5. 为了「有趣」加入 emoji、弹跳、音效或任何假数据。
- **不应复用的旧版语法**：静态三等分「原话 / AI 整理 / 用户确认」卡片阵列（与首屏示意重复）；装饰性圆点列表；通用圆角胶囊标签。

## 工程规则（本轮新增）

- **交互岛不含任何可见文案**：`landing-bench.js` 里不出现中文字符串；全部用户可见文案由 `page.js`（Server Component）以 `sentences` / `copy` props 传入。这样所有对外文案仍集中在一个可审计的文件里，也让 `tests/landing-bc-contract.test.mjs` 对 `page.js` 的文案断言继续有效。
- **交互岛不触碰浏览器全局**：不读 `window` / `document`，不注册全局监听；只用 React 状态。SSR 与客户端首帧一致，无 hydration 分歧。
- **确定性的声波**：每个句子的声波形状由该句文本的确定性散列派生，不使用 `Math.random`，同一句每次渲染形状一致。
